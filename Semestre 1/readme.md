
# 🏅 SESI Esporte Amparo — Semestre 1

## 📖 Sobre o Projeto

Este diretório reúne os arquivos, atividades e materiais desenvolvidos durante o primeiro semestre do projeto **SESI Esporte Amparo**.

O objetivo é manter os conteúdos organizados, facilitar o acompanhamento do desenvolvimento do projeto e registrar os trabalhos realizados ao longo do semestre.

## 🎯 Objetivos

- 📚 Organizar os materiais e as atividades do semestre.
- 💻 Centralizar os arquivos relacionados ao projeto.
- 📈 Acompanhar a evolução das atividades desenvolvidas.
- 🗂️ Manter um histórico dos trabalhos realizados.
- 🤝 Facilitar o acesso e a consulta aos materiais.
